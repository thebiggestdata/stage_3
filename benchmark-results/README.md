# Benchmark Results

This directory contains the benchmark artefacts used in the Stage 3 report.

## Contents

- `jmeter/raw/`: raw JMeter CSV samples exported from the five search query groups.
- `jmeter/jmeter-global-summary.csv`: combined JMeter results for 3, 6 and 9 nodes.
- `jmeter/jmeter-per-query-summary.csv`: per-query JMeter results.
- `jmeter/jmeter-workload.csv`: workload definition used in JMeter.
- `module/benchmark-module-summary.csv`: final results from the internal benchmark module.
- `module/benchmark-module-raw-results.md`: console summaries for ingestion, indexing and recovery benchmarks.

Images generated by JMeter were intentionally excluded because the report already contains the relevant tables and plots, and the CSV files are the reproducible source data.

## Node Configurations

- `3nodes`: one physical machine running ingestion, indexing and search.
- `6nodes`: two physical machines, each running ingestion, indexing and search.
- `9nodes`: three physical machines, each running ingestion, indexing and search.

## JMeter

JMeter measured the public search endpoint through Nginx:

```text
http://localhost:8080/search
```

The raw CSV files are organized as:

```text
jmeter/raw/<cluster>/<query-group>/summary-report.csv
```

Each raw CSV contains one row per HTTP sample.

## Internal Benchmark Module

The internal benchmark module connects to Hazelcast as a client and measures distributed state changes:

- `ingestionrate`: growth of `downloaded-books`.
- `indexingthroughput`: growth of `book-token-counts:<generation>`.
- `recoverytime`: time until the cluster becomes available and stable after a service failure.
